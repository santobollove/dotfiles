# Dotfiles 🛠️

My personal configuration for a minimalist, efficient Linux environment.

## 📂 Repository Structure
This repository manages configurations for my shell, window manager, and personal automation scripts.

```text
.
├── .config/            # Application-specific configurations (tmux, X11, zsh)
├── .local/src/         # Source code for custom builds (dwm)
├── Machine/            # Personal automation & environment-specific files
│   ├── bin/            # Custom executable binaries
│   ├── scripts/        # Helper scripts (e.g., screenshots)
│   ├── Wallpaper/      # Wallpaper management scripts
│   └── zsh/            # Modular alias and function definitions
├── .zshrc              # Main shell entry point
└── README.md           # This documentation
```
